# Правила матча и экономика карты (Gate 1 атласа CS2)

Пакет «CS2 Combat Atlas, 2 тома × 500 A4» (19.10.2026) предлагает перестраивать матч-движок
по воротам: Gate 0 — осмотр, Gate 1 — версионируемые правила и журнал денег, Gate 2 — автомат
раунда, дальше карта, дуэли, реальные демки. Здесь сделан только Gate 1. Модуль
`src/csmcore/match/` пока **не подключён** к `engine.py`: игра играет как раньше.

## Gate 0: что в атласе и что уже есть в коде

- Из 1000 страниц 10 методические, остальные 990 — синтетические кейсы, собранные генератором
  `create_atlas.py` из шаблона. У всех кейсов ~15 разных «ожидаемых свойств» (инвариантов), а не
  990 разных. Ценное в пакете: инварианты, список источников S01–S18, шаблон правил, бриф с
  воротами и примерами приёмки. Вероятности в кейсах сам атлас называет необученными.
- Утилита выгрузки демок `cs2_demo_text_export.py` повторяет то, что уже есть:
  `scripts/demo_analysis.py` + `csmcore/demo_records.py` + `matchstats.py` (тот же demoparser2).
  Новое в ней — манифест с sha256 файла демки и версией парсера. Не добавлена, чтобы не
  дублировать; манифест стоит перенести в наш скрипт, когда появятся настоящие демки.
- План движка `docs/match-engine-plan.md` уже содержит те же шаги (стороны и овертайм, экономика,
  бомба и время, трейды, клатчи, гранаты). Атлас совпадает с ним по порядку и добавляет
  требование версионировать правила по турниру.
- В фикстурах у 594 из 990 кейсов обе команды одновременно на серии поражений. Это не ошибка:
  в CS2 победа уменьшает счётчик поражений на один, а не обнуляет его.

порядок. Это и есть довод атласа за версионирование правил по турниру.

## Что сделано (Gate 1)

- `match/rules.py`: `Rules` с версией и статусом каждого поля, пресеты `premier-2026` и
  `major-2026`, `preset(name, **исключения)`. Исключения турнира помечаются как модель.
- `match/economy.py`: `MapEconomy` — деньги каждого игрока, счётчики поражений сторон, журнал
  каждой записи (сколько просили, сколько зачтено после пола 0 и потолка 16 000, остаток).
  Покупка в долг отклоняется. Убийство платит только убийце. Конец раунда принимает только
  законную причину: после закладки CT побеждает лишь дефьюзом, взрыв невозможен без закладки.
  Смена сторон в перерыве, деньги овертайма.
- `tests/test_match_economy.py`: тождество журнала проверено с каждого из 990 синтетических
  состояний атласа, лестница бонусов, потолок, тимкилл, законные причины конца раунда,
  детерминизм, неизменность текущего движка. Из фикстур взяты только экономические поля
  (`tests/data/atlas_fixtures_economy.jsonl`).
